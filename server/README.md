
# **Destinify** - Server  
This is the server folder containing all the backend codes, ML models, datasets and Database code written for the app in *Flask (Python)*.


## **Installation**
Just run the code:
```bash
  pip install -r requirements.txt
  python app.py
```
and the server gets running on *localhost:5000*


    
### **Tech Stack**
    
**ML Models/Datasets/APIs** - Flask, Kaggle, Google-places API, Calindrific API, OpenAI (gpt-4o)\
**Database** - MongoDB
